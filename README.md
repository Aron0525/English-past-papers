# English-past-papers

大学英语四级、六级、英语专业四级、英语专业八级真题的本地备考工作台，含源码与题库数据。

主项目在 `zhenti-local/`，功能细节看 [`zhenti-local/README.md`](zhenti-local/README.md)。本文件只讲仓库怎么用。

## 仓库结构

| 路径 | 内容 |
|---|---|
| `zhenti-local/` | 完整项目。Node 服务端、前端页面、采集与建索引工具、使用文档 |
| `zhenti-local/data/` | 题库。按考试分目录，每套一个子目录，内含原卷 PDF、听力音频、答案解析、元数据 |
| `zhenti-local/tools/` | 采集、OCR、建索引、词典构建脚本 |
| `zhenti-local/docs/` | 架构说明、逆向记录、界面截图 |

## 收录规模

合计 173 套，`data/` 约 2.3 GB，含 PDF 原卷 441 份、听力音频 88 段、索引与解析 JSON 258 个。

## 跑起来

需要 Node.js 18 以上。项目零依赖，不用 `npm install`。

```bash
cd zhenti-local
./start.sh              # Windows 双击 start.bat
```

脚本会自己找 node，端口被占用就从 8787 往后顺延到 8799，服务就绪后打开浏览器。也可以指定端口或者不开浏览器。

```bash
./start.sh 9000
./start.sh 9000 --no-open
node server.mjs --port 8787     # 手动起
```

打开 `http://127.0.0.1:8787/`。

## 克隆注意

仓库体积 2.3 GB，绝大部分是 PDF 与音频这类二进制文件。全量克隆慢，只想要代码和索引的话用浅克隆并跳过数据目录。

```bash
git clone --depth 1 https://github.com/Aron0525/English-past-papers.git
```

## 不在仓库里的东西

`data/` 里的题库是完整上传的，没有任何删减。以下内容属于本机采集现场，已由 `.gitignore` 排除，只留在本地。

- `cet4/`、`cet6/`、`tem4_archive/`、`tem8/` 四个原始素材目录，是题库导入前的现场存档
- `bv/`、`.cache/`、`.inspect/` 里的浏览器配置副本与缓存，合计超过 1.6 GB
- 根目录下的探针输出、日志、页面快照等临时文件

这些目录不会出现在 clone 下来的仓库里。`zhenti-local/README.md` 里提到的 `tem4_archive/` 与 `tem8/` 素材目录，指的就是这些本地存档。

## 用途边界

题库素材来自公开网络上的真题分享站点，采集与整理仅用于个人备考和本地阅读。版权归各试题出版方与来源站点所有，不要用于商业分发。
